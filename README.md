**Intern:** Bapan Ghosh  ·  **Ref:** CTI/A1/C410735  ·  **Domain:** Web Development

A single, connected, **premium multi-page website** that houses every internship task — with a shared
luxury design system, site-wide navigation, real photography and two full interactive applications.

---

## ▶ How to run

Open **`index.html`** — it is the home page and links to every task through the top navigation.
Best viewed in a modern browser (Chrome, Edge, Firefox). No installation needed.

> Most pages work fully **offline**. Two pages load their framework from a CDN, so keep the internet on
> for the best experience: **Level 2 · Frameworks (Bulma)** and **Level 2 · Grid (Bootstrap)**.
> All photographs are stored **locally** inside `assets/img/`, so images always appear.

Live Demo: https://cognifyz-internship-tasks-bapan.netlify.app/
